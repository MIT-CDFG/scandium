## What it depicts, and what it deliberately does not

A rounded square in the shell's window ground; the **canvas motif** — one light
rectangle, lower right, the largest element — and the mark **`Sc`** set clear of
it in the upper left.

**It is not a periodic-table tile, and that took three attempts rather than an
assertion.** The tile look is three things together: an enclosing bordered
square, a large centred symbol, and a small number in a corner.

* **v1** drew exactly that. It was rendered, looked at, and rejected — while the
  code comment above it claimed the opposite. A comment asserting a property the
  artifact does not have is worth less than no comment.
* **v2** removed the border and overlapped the mark with the canvas; the `c` was
  half-swallowed and it read as a rendering fault.
* **v3**, this file, keeps the canvas dominant and the mark clear of it.

**The atomic number is absent on purpose.** WORD 9 permits `Sc / 21`; it does not
require it, and dropping the corner number removes the third of the three
features that make a tile a tile. There is no element name and no atomic mass.
